# Privicoin  

Privicoin is a frontend project built with React for managing and visualizing cryptocurrency-related features.  
This repository provides the source code, setup, and deployment steps.  

---

## 🚀 Getting Started  

Follow the steps below to set up and run the project locally or in production.  

### 1. Clone the repository  

```bash
git clone https://github.com/Laurence-Personal-Projects/privicoin.git
cd privicoin
```

### 2. Install dependencies

```bash
npm install
```

### 3. To Run locally

Start the local development server with hot-reloading:
```bash
npm run start
or
npm run watch
```

### 4. To Build for production
```bash
npm run build
```

### 5. To Run all unit tests
```bash
npm run test
```

### 6. Run a specific test file
```bash
npm test -- Button.test.jsx
```
